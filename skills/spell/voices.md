# Voice examples

Part of the spell skill (`core.md` beside this file). Read this file when the message tells how the voice was made, the user asks to hear earlier versions of the voice, or the text already contains `[voice: …]` markers.

When the message being read tells how the voice was made, or the user asks to hear earlier versions of the voice, a paragraph may be spoken in another version. Start that paragraph with a marker, and announce it in the paragraph before ("This is the base voice."). Keep an example to one or two short sentences, and use the same sentence for each version so they can be compared.

- `[voice: base]` the speech model alone, with no effect
- `[voice: metal]` the Adjutant's delivery with only the metallic doubling
- `[voice: early]` the full effect as it was before the clarity changes
- `[voice: current]` the voice as it is now (the same as no marker)

If the message on screen already contains such markers, keep them exactly where they are.
